# 🛒 SkyMart - E-Commerce Web App

A full-stack e-commerce web application built with React, TypeScript, Tailwind CSS and FastAPI.

## 🌐 Live Demo
👉 [ecommerce-shop-kappa-six.vercel.app](https://ecommerce-shop-kappa-six.vercel.app)

## 🚀 Features
- 🛍️ Product listing and search
- 🛒 Shopping cart functionality
- 💳 Checkout system
- 📱 Fully responsive design
- ⚡ Fast and modern UI

## 🛠️ Tech Stack

| Frontend | Backend |
|----------|---------|
| React | FastAPI |
| TypeScript | Python |
| Tailwind CSS | REST API |
| Vite | |

## 📁 Project Structure


ecommerce-shop/
├── src/          # React frontend
├── api/          # FastAPI backend
├── public/       # Static assets
└── index.html    # Entry point

## ⚙️ Installation

### Frontend
```bash
npm install
npm run dev
```

### Backend
```bash
cd api
pip install -r requirements.txt
uvicorn main:app --reload
```
